## 二、资源压缩详情

### 2.1 视频压缩（-85%）

**原始状态**：
- 格式：MP4 (H.264 + AAC)
- 分辨率：1920×1080
- 码率：5.5-13 Mbps（含音频轨）
- 总大小：41 MB

**压缩策略**：
- 移除音频轨（`-an`）— 游戏内视频无需音频
- 降低码率至 1.5 Mbps（`-b:v 1500k`）
- 保持 1080p 分辨率，优先保证视觉质量

**压缩结果**：
| 视频文件 | 原始 | 压缩后 | 节省 |
|---------|------|--------|------|
| chapter1start.mp4 | 5.4 MB | 0.8 MB | -85% |
| chapter1end2.mp4 | 6.0 MB | 0.9 MB | -85% |
| chapter2end.mp4 | 6.9 MB | 1.0 MB | -86% |
| chapter3end.mp4 | 7.2 MB | 1.0 MB | -86% |
| chapter4end.mp4 | 6.3 MB | 0.9 MB | -86% |
| chapter5end.mp4 | 6.1 MB | 0.8 MB | -87% |
| chapter6end.mp4 | 3.3 MB | 0.5 MB | -86% |
| **合计** | **41 MB** | **6.2 MB** | **-85%** |

**命令示例**：


## 四、资源预加载实现

### 4.1 实现目标

1. **启动时预加载全部资源**：避免游戏中按需下载导致卡顿
2. **显示加载进度**：给用户加载反馈，提升体验
3. **加载完成后才可交互**：确保游戏流畅性

### 4.2 技术方案

**核心组件**：`src/utils/ResourcePreloader.ts`

**实现要点**：
1. **并发下载**：使用 6 个并发 Promise 同时下载
2. **实时进度**：通过 `fetch` 的 `body.getReader()` 监听字节流
3. **进度回调**：提供 `onProgress(loaded, total)` 回调
4. **缓存机制**：下载后存入浏览器缓存，后续 Three.js/Audio/Video 加载时命中缓存

**API 设计**：
```typescript
class ResourcePreloader {
  constructor(urls: string[])
  
  preload(
    onProgress: (loaded: number, total: number) => void
  ): Promise<void>
}
```

### 4.3 UI 交互流程

**StartScreen.ts 改造**：

1. **初始状态**：显示标题，隐藏"开始旅程"按钮
2. **加载中**：显示进度条和百分比
3. **加载完成**：进度条消失，显示"开始旅程"按钮，用户可点击

**进度更新示例**：
```typescript
const preloader = new ResourcePreloader(allAssetUrls)
const total = preloader.getTotalSize()

preloader.preload((loaded, total) => {
  const percent = Math.round(loaded / total * 100)
  startScreen.updateProgress(percent)
})
```
